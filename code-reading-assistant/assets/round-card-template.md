# 本轮学习卡（完整讲透 · 框架辅助记忆模板）

> 每轮像一节期末复习冲刺课：把涉及的知识点完整、明确地讲透，宁全勿略、不设字数上限；同时画一个知识框架图辅助记忆。删掉“好的 / 下面”等口水话，但别为省字数把该讲的压成一句结论。

【定位】一句话：读了 <文件 / 函数 / 行号范围>，做了什么定位（用户无需记命令）。

【框架】先画一个知识框架图（层级 / 流程图 / 关系图，文字图或 Mermaid 均可）作为记忆锚点，再用文字讲清主线：
- 入口：…
- 数据流：A → B → C（关键路径）
- 职责：本模块 / 函数负责…（不负责…）
- 边界：关键路径止于此 / 未覆盖…
- 验证：测试 / 运行如何覆盖（未读标“未读”）

【重点】把各节知识点逐条讲透（不只一句结论：讲清是什么 / 为什么 / 边界 / 常见误区），每条「要点 @文件:行号（属框架第 X 节）」；已讲透的概念在后续轮次只回指、不重讲（见 progress.md「已教概念」）：
1. … @a.py:12-20（入口）——讲透：…
2. 依赖注入：… @b.py:8（职责）——讲透：…

【出题】仅基于上面框架 + 重点，1–2 问并标维度；凡未讲过的函数 / 例子 / 条件不得考：
Q1（核心逻辑）：用自己的话说明 … 的数据流。
Q2（依据出处）：指出 … 在 … 的哪一行，依据是什么。
